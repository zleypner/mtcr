# Backlink Strategy

## Ethical Approach

This site exists to provide genuine value to medical tourists. Backlinks must always:

1. **Exist in valuable content** - Never create thin content just for links
2. **Be editorial in nature** - Genuine recommendations, not paid placements
3. **Benefit the user** - Help readers find quality care
4. **Follow guidelines** - No link schemes or manipulation

## Internal Backlink Opportunities

### Yieldge Client Integration

When Yieldge clients are featured:

**Acceptable:**
- Directory listing with complete profile
- Inclusion in "Best Clinics for X" if genuinely qualified
- Mention in treatment guides when relevant
- Patient story features (real patients only)
- Comparison articles with objective criteria

**Not Acceptable:**
- Thin pages created solely for links
- Forced mentions in unrelated content
- Fake reviews or testimonials
- Hidden or deceptive links
- Link exchanges

### Link Value Requirements

Before adding any provider link, verify:

1. Provider is licensed and accredited
2. Content provides genuine information
3. Link is contextually relevant
4. User would find the link helpful
5. Content meets quality standards

## Directory Strategy

### Featured Listings

Provider directories with:
- Complete profiles
- Verified information
- User reviews
- Direct contact info

### Listing Quality Standards

Every directory entry must include:
- Accurate business information
- Verified accreditations
- Real photography
- Current contact details
- Honest service descriptions

## Link Audit

### Monthly Review

Check all external links for:
- Link rot (404s)
- Changed content
- Quality degradation
- Relevance

### Remove Links That

- Point to low-quality sites
- No longer serve users
- Have been requested removed
- Violate guidelines

## Reporting

Track metrics without manipulation:
- Organic backlink acquisition
- Referring domains
- Link quality scores
- Traffic from referrals

## Documentation

Maintain records of:
- All outreach attempts
- Partnership agreements
- Editorial decisions for links
- Link removal requests
