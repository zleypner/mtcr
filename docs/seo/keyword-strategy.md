# Keyword Strategy

## Keyword Categories

### 1. Treatment Keywords

```
[treatment] costa rica
[treatment] in costa rica
best [treatment] costa rica
[treatment] cost costa rica
affordable [treatment] costa rica
```

**Examples:**
- dental implants costa rica
- rhinoplasty costa rica
- knee replacement costa rica
- lasik costa rica

### 2. Provider Keywords

```
best [specialty] costa rica
best [specialty] doctors costa rica
top [specialty] clinics costa rica
[specialty] hospitals costa rica
```

**Examples:**
- best dentist costa rica
- best plastic surgeon costa rica
- top orthopedic doctors costa rica

### 3. Informational Keywords

```
medical tourism costa rica [year]
is medical tourism safe in costa rica
how much does [treatment] cost in costa rica
costa rica healthcare quality
```

### 4. Comparison Keywords

```
[treatment] costa rica vs usa
[treatment] costa rica vs mexico
[treatment] costa rica vs thailand
costa rica vs [country] medical tourism
```

### 5. Location Keywords

```
medical tourism san jose costa rica
hospitals in [city] costa rica
doctors in [city] costa rica
```

## Long-Tail Strategy

Focus on specific, high-intent queries:

```
how much do dental implants cost in costa rica
best plastic surgeon for rhinoplasty in costa rica
jci accredited hospitals in costa rica
is it safe to get surgery in costa rica
costa rica medical tourism packages all inclusive
```

## Keyword Research Process

1. **Seed Keywords**: Start with core topics
2. **Expand**: Use tools (Ahrefs, SEMrush)
3. **Analyze Intent**: Categorize by user intent
4. **Map**: Assign to content types
5. **Prioritize**: Based on volume, difficulty, relevance
6. **Track**: Monitor rankings
